# Генеральная уборка — сайт (статическая версия)

Статическая версия сайта клининговой компании «Генеральная уборка» (Иркутск) для размещения на GitHub Pages.

## Страницы
- `index.html` — главная
- `price.html` — цены
- `business.html` — для бизнеса (обзор)
- `abonement.html` — абонентское обслуживание
- `razovye.html` — разовые услуги
- `partners.html` — клиенты и документы

Все страницы связаны между собой через шапку (меню/бургер) и внутренние ссылки.

## Примечание
Это плоская статическая сборка (относительные ссылки вида `page.html`), собранная из исходных блоков для Tilda. Часть данных — плейсхолдеры, которые заполняет заказчик: логотипы клиентов, сканы благодарственных писем, реквизиты компании (ИНН/КПП/ОГРН/счета), детали кейсов.
